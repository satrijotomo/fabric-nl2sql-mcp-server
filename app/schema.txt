Relationships:

- users.id = accounts.user_id
- accounts.id = transactions.from_account_id
- accounts.id = transactions.to_account_id
- users.id = chat_sessions.user_id
- chat_sessions.session_id = agent_traces.session_id
- chat_sessions.session_id = tool_usage.session_id
- chat_sessions.session_id = chat_history.session_id
- agent_definitions.agent_id = tool_definitions.tool_id

Business meaning:

- Users own accounts
- Transactions move money between accounts
- Users start chat sessions
- Chat sessions involve agents and tools
- Agent traces record execution steps
- Tool usage captures LLM tool activity
- Chat history stores messages

Rules:

- Always use dbo schema
- Only use listed tables
- Prefer JOINs when relationships exist
- Use GROUP BY for aggregations
- Use TOP for limiting rows
- Do not use sys tables
- Think like a data analyst when answering questions
